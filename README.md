# FLIPKAR_CLEANING_VISUALISATION-PYTHON
A Python-based data analytics project that performs data cleaning, preprocessing, exploratory data analysis (EDA), statistical analysis, and data visualization on Flipkart product data using Pandas, NumPy, Matplotlib, and Seaborn to uncover pricing, ratings, discounts, and product trends.

# 🛒 Flipkart Product Data Analysis using Python

## 📖 Project Overview

This project focuses on cleaning, preprocessing, analyzing, and visualizing Flipkart product data using Python. The objective is to transform raw e-commerce data into meaningful insights through Exploratory Data Analysis (EDA), statistical summaries, and informative visualizations.

The notebook demonstrates essential data analytics techniques commonly used by Data Analysts and Business Analysts to understand product performance, pricing strategies, customer ratings, and discount patterns.

---

# 🎯 Objectives

- Import and inspect the Flipkart dataset.
- Clean missing and inconsistent data.
- Handle duplicate records.
- Perform Exploratory Data Analysis (EDA).
- Generate descriptive statistics.
- Identify pricing and rating trends.
- Analyze product categories and discounts.
- Create professional visualizations using Matplotlib and Seaborn.
